# 监督对比 + MoCo：四组对照

真实 batch=4，effective batch 32（梯度累积 8 步），seed 42，其余超参与 `deberta_lora`
那次（测试集 0.9633）完全一致。单卡 Tesla T4。四组之间只差方法本身与动量系数。

由 `experiments/moco/collect_results.py` 与 `experiments/moco/significance.py` 生成。

## 队列与动量分支

| 方法 | 每 query 候选数 | 队列有效长度 | 队列标签分布 | q·k 余弦 | 对比目标完成度 |
| --- | --: | --: | --- | --: | --: |
| SCL | 4 | — | — | 0.998 | 87% |
| SCL-MoCo m=0.999 | 4100 | 4096 | {0: 1977, 1: 2119} | 0.515 | 21% |
| SCL-MoCo m=0.99 | 4100 | 4096 | {0: 1977, 1: 2119} | 1.000 | 79% |


`q·k` 与「对比目标完成度」这两个诊断量是跑完 m=0.999 那轮之后才加进代码的，
所以 SCL 与 m=0.999 两行的数值是事后按公式从已落盘的 `view_gap` 和对比损失换算的，
只有 m=0.99 那行是训练时直接记录进 summary 的。换算口径见 `trainer_scl._record_progress`。

- **q·k**：同一句话分别过 query 编码器和动量 key 编码器，两个特征的余弦相似度。
  MoCo 里这一对就是要被拉近的正样本对，它低意味着模型在对齐一个陈旧的目标。
- **对比目标完成度**：候选数为 N 时，特征完全塌缩的损失恰好是 log(N)，完美分开有解析下界，
  实测值落在两者之间的位置就是完成度。只看损失的绝对值会被 log(N) 这个常数骗过去 ——
  m=0.999 那轮损失从 8.28 缓慢降到 8.17，看着在收敛，其实 log(4100)=8.32 就是完全没学的值。

m=0.999 与 m=0.99 的诊断量对比（同一个 seed，只差动量系数）：

| optimizer step | q·k m=0.999 | q·k m=0.99 | 完成度 m=0.999 | 完成度 m=0.99 |
| --: | --: | --: | --: | --: |
| 50 | +0.941 | +0.952 | 0% | 0% |
| 100 | +0.119 | +0.172 | 4% | 7% |
| 200 | +0.065 | +0.553 | 7% | 23% |
| 260 | +0.004 | +0.855 | 7% | 43% |
| 600 | +0.529 | +0.999 | 13% | 80% |
| 1250 | +0.515 | +1.000 | 21% | 79% |

两轮都在 step 100 附近出现一次塌陷，位置正好是 warmup 结束、学习率冲到峰值的时刻
（`warmup_ratio=0.06` × 1250 ≈ 75 步），此时随机初始化的 projection head 方向转得最快。
区别在于恢复：m=0.99 很快追回并稳定在 1.0，m=0.999 一直在 0~0.5 之间震荡。

## 显著性

McNemar 精确检验（只用两个模型判断不一致的样本），24,961 条打分样本，
accuracy≈0.96 时单模型的二项标准误是 0.124 个百分点，1 条样本 = 0.0040 个百分点。

| 对比 | 差值（百分点） | 只有前者对 | 只有后者对 | p |
| --- | --: | --: | --: | --: |
| Baseline vs SCL | −0.064 | 155 | 171 | 0.406 |
| Baseline vs SCL-MoCo m=0.999 | +0.012 | 124 | 121 | 0.898 |
| Baseline vs SCL-MoCo m=0.99 | −0.048 | 160 | 172 | 0.546 |
| SCL vs SCL-MoCo m=0.999 | +0.076 | 145 | 126 | 0.274 |
| SCL vs SCL-MoCo m=0.99 | +0.016 | 82 | 78 | 0.813 |
| SCL-MoCo m=0.999 vs m=0.99 | −0.060 | 127 | 142 | 0.393 |

| 对比 | 预测概率 Pearson r | 硬标签一致率 |
| --- | --: | --: |
| Baseline vs SCL | 0.9928 | 0.9869 |
| Baseline vs SCL-MoCo m=0.999 | 0.9944 | 0.9902 |
| Baseline vs SCL-MoCo m=0.99 | 0.9925 | 0.9867 |
| SCL vs SCL-MoCo m=0.999 | 0.9952 | 0.9891 |
| SCL vs SCL-MoCo m=0.99 | 0.9982 | 0.9936 |
| SCL-MoCo m=0.999 vs m=0.99 | 0.9953 | 0.9892 |

六个 p 值全部大于 0.27，四组极差 0.08 个百分点（20 条样本），小于单模型标准误。
概率相关系数都在 0.99 以上、硬标签一致率都在 98.7% 以上 —— 四个模型基本是同一个模型。

**结论：队列与动量编码器都确实在工作（候选规模放大 1025 倍，诊断量可查），
但准确率上分不出差别。** 每组只有一个 seed，所以这里说的是「看不出差别」，
不是「证明没有差别」。

## 缺的对照

- 真实 batch=16 的三组（约 3.9 h）：任务里「小 batch 是否导致 SCL 退化」这条判断
  需要它才能直接回答。
- 每组 3 个 seed（约 9.6 h）：0.08 个百分点的差异必须靠 mean±std 才能定性。
- λ 扫描：SCL-MoCo 的对比损失量级是 SCL 的 8.7 倍，固定 λ=0.2 时两组的有效正则强度
  差很多，不扫 λ 分不清「队列有没有用」和「正则强度合不合适」。

没跑就是没跑，表里不填估计值。
